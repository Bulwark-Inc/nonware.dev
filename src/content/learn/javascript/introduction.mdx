# Introduction to JavaScript

JavaScript is a programming language used to make websites and applications interactive.

It runs in web browsers, but it can also run outside the browser using environments such as Node.js.

In this tutorial, you'll learn JavaScript from the fundamentals and gradually use it to build practical things.

## What You'll Learn

Throughout this tutorial, you'll learn how to:

- Write and run JavaScript code
- Work with variables and different data types
- Use conditions and loops
- Create and use functions
- Work with arrays and objects
- Manipulate web pages with JavaScript
- Work with asynchronous code
- Fetch data from APIs
- Build practical JavaScript projects

## Where JavaScript Is Used

JavaScript is commonly used for:

- Interactive websites
- Web applications
- Backend services
- APIs
- Browser extensions
- Desktop applications
- Mobile applications
- Automation and scripting

The same language can therefore be used across many parts of modern software development.

## JavaScript in the Browser

When you open a website, your browser can execute JavaScript code directly.

For example:

<CodeBlock language="javascript">
console.log("Hello, JavaScript!");
</CodeBlock>

This tells JavaScript to print a message to the console.

## JavaScript Outside the Browser

JavaScript is not limited to web browsers.

With Node.js, you can run JavaScript directly on your computer.

For example:

<Terminal>
node
</Terminal>

You can then enter JavaScript directly into the Node.js interactive environment.

## JavaScript and HTML

JavaScript can work together with HTML and CSS to create interactive websites.

For example, JavaScript can:

- Respond to button clicks
- Change page content
- Validate forms
- Fetch data from a server
- Update elements without reloading the page

This is one of the main reasons JavaScript is so important for web development.

## A Simple Example

Here's a small JavaScript program:

<CodeBlock language="javascript">
const name = "Developer";

console.log(`Hello, ${name}!`);
</CodeBlock>

The program stores a value in a variable and then uses it to create a message.

<ExpectedOutput>
Hello, Developer!
</ExpectedOutput>

## Key Takeaways

- JavaScript is a programming language used extensively in modern web development.
- JavaScript can run in browsers and outside browsers.
- Node.js allows JavaScript to run on your computer and on servers.
- JavaScript can interact with HTML and CSS to create interactive websites.
- You'll learn the language step by step throughout this tutorial.
