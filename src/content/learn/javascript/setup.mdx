# Setting Up Your Environment

Before we start writing JavaScript, let's make sure you have the tools you need.

You don't need a complicated setup to learn JavaScript. We'll start with a simple development environment that allows you to write, run, and test JavaScript code.

## What You'll Need

For this tutorial, you'll need:

- A computer
- A modern web browser
- Node.js
- A code editor

We'll use Visual Studio Code as the code editor throughout this tutorial.

## Install a Code Editor

A code editor is where you'll write your JavaScript code.

We recommend Visual Studio Code because it is free, widely used, and has excellent JavaScript and TypeScript support.

You can use another editor if you prefer, but the examples in this tutorial will use Visual Studio Code.

## Install Node.js

Node.js allows you to run JavaScript outside the browser.

After installing Node.js, open a terminal and check that it is available.

<Terminal>
node -v
</Terminal>

You should see a version number.

<ExpectedOutput>
v20.x.x
</ExpectedOutput>

Your exact version may be different. The important thing is that Node.js is installed and available from your terminal.

<Note>
Use an active LTS version of Node.js when possible.
</Note>

## Check npm

Node.js also includes npm, the Node.js package manager.

Check that npm is available:

<Terminal>
npm -v
</Terminal>

You should see an npm version number.

<ExpectedOutput>
10.x.x
</ExpectedOutput>

Again, your exact version may be different.

## Create a Project Folder

Let's create a folder where we'll keep the JavaScript exercises from this tutorial.

<Terminal>
mkdir javascript-learning
cd javascript-learning
</Terminal>

You can choose a different folder name if you prefer.

## Open the Folder in Visual Studio Code

If the `code` command is available on your system, you can open the folder with:

<Terminal>
code .
</Terminal>

Otherwise, open Visual Studio Code manually and select the project folder.

## Your Environment Is Ready

At this point, you should have:

- A code editor
- A modern browser
- Node.js
- npm
- A folder for your JavaScript projects

That's enough to begin writing JavaScript.

## Key Takeaways

- You need a code editor to write JavaScript.
- Node.js lets you run JavaScript outside the browser.
- npm comes with Node.js.
- A dedicated project folder keeps your exercises organized.

Everything is ready.
