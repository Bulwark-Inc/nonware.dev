# Installing Next.js

In this lesson, you'll install everything you need
to create your first Next.js application.

## Check Node.js

Before installing Next.js, let's verify that Node.js
is available.

<Terminal>
node -v
</Terminal>

<ExpectedOutput>
v20.x.x
</ExpectedOutput>

<Note>
Use an active LTS version of Node.js.
</Note>

## Create your application

Run the following command:

<CodeBlock language="bash">
npx create-next-app@latest my-first-app
</CodeBlock>

<Tip>
For this tutorial, you can use the recommended defaults.
</Tip>
